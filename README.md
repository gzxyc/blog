# 孤城 · 个人博客

一个**零成本**的**纯静态**个人网站：**没有构建步骤，没有服务端依赖，可以部署在任何静态托管平台上**。

年支出 **0 元**，无需服务器、无需数据库、无需本地构建环境，也**不需要买域名**——用托管平台自带的地址就能完整上线。

> 目前托管在 GitHub Pages 上（`https://gzxyc.github.io/blog/`），但这只是一个**选择**，不是前提。
> 换到企业托管平台、内网服务器或对象存储时，站点本体不用改，只有 `sitemap.xml` 和 `robots.txt` 两个文件需要跟着改地址。详见下方「更换托管平台」。

---

## 为什么能随便换平台

全站只有静态文件，并且遵守三条约定，所以搬动时几乎零成本：

| 约定 | 效果 |
| --- | --- |
| **没有构建步骤** | 目录里是什么，线上就是什么。不存在「本地能跑、线上构建失败」这类故障 |
| **全站相对路径** | 资源一律写 `assets/…`、`content/…`，放在根目录、子目录、任何域名下都能跑 |
| **地址不写死在页面里** | `canonical` 与 `og:url` 由脚本在运行时按**真实访问地址**推导，换域名换路径自动对准 |

## 这套方案的特点

| 特性 | 说明 |
| --- | --- |
| **零构建** | 纯 HTML / CSS / 原生 JavaScript。改完直接生效 |
| **平台无关** | 静态托管服务、企业托管平台、内网服务器、对象存储、本地离线，都能跑 |
| **可视化后台** | 在浏览器里写文章改配置，手机上也能发文（取决于托管平台是否支持文件写入） |
| **响应式** | 手机、平板、桌面自适应；支持浅色 / 深色主题自动跟随系统并记忆选择 |
| **六套主题** | 内置铅墨 / 磐石 / 刊页 / 白纸 / 暖宣 / 终端，后台一个下拉框切换，各带明暗两套配色 |
| **站内搜索** | 纯前端全文检索，覆盖标题、摘要、正文、标签 |
| **无外链依赖** | Markdown 渲染库已本地化到 `assets/vendor/`，不依赖任何 CDN |

│

## 本地预览

因为站点用 `fetch()` 读取 `content/` 下的 JSON，**不能直接双击打开 index.html**（`file://` 协议会被浏览器拦截），需要用一个 HTTP 服务器：

```bash
node tools/serve.mjs
# 然后打开 http://localhost:8080
```

想换端口：`node tools/serve.mjs 3000`

## 部署到任意平台

本质是同一件事：**把整个目录原样放上去**。

### 静态托管服务（如各类 Pages 服务）

把目录推到代码仓库，平台设置里指定「发布目录 = 根目录、分支 = 默认分支」。文件更新后通常会自动重新发布，约 30 秒到 1 分钟生效。

### 企业托管平台 / 内网服务器

交给 Nginx、Apache 或 IIS，站点根目录指向它即可。确认两点：`.json` 能被正常返回；把 `404.html` 配成服务器的 404 响应页。不需要任何运行时。

### 对象存储（OSS / COS / S3 等）

开启「静态网站托管」模式，上传整个目录，默认首页 `index.html`、错误页 `404.html`。注意：不开这个模式，访问会变成下载文件。

### 更换托管平台时要改什么

只有两个文件，因为**站点地图协议要求绝对地址**，页面无法在运行时替它推导：

| 文件 | 改什么 |
| --- | --- |
| `sitemap.xml` | 把所有 `<loc>` 里的站点地址换成新地址 |
| `robots.txt` | 把最后一行的 Sitemap 地址换成新地址 |

另外记得在后台「**站点设置 → 站点地址**」里同步更新（该字段仅供记录与日后参考）。

页面里的 `canonical` / `og:url` **不用管**——脚本按真实访问地址自动生成。

## 可选：一条龙部署脚本

`tools/deploy.mjs` 是一个**可选的**便捷脚本，面向「代码托管 + 自动发布」这一类平台，帮你串起建仓、推送、开启 Pages 这几步：

```bash
node tools/deploy.mjs \
  --user=你的用户名 \
  --repo=仓库名 \
  --token=你的访问令牌
```

**它不是必需的。** 你也可以完全不用它，直接把目录上传到托管平台。

| 开关 | 作用 |
| --- | --- |
| `--domain` | 可选。填上会一并绑定自定义域名；不填则用平台默认地址 |
| `--force` | 远程有本地没有的提交时强制覆盖。⚠️ 会丢弃远程上的提交——若它来自可视化后台，就等于丢掉后台的编辑。默认会自动合并，通常用不到 |
| `--skip-pages` | 只推代码，不调用接口配置 Pages |
| `--dry-run` | 只做参数检查，不提交不推送 |

> **关于「远程有本地没有的提交」**：你在可视化后台每保存一次，后台就会往仓库提交一次。所以从本地推送前，远程往往已经比你新。脚本**会自动拉取并合并**这些改动再推送，不会覆盖后台内容。

## 日常使用

### 写文章

1. 打开可视化后台，登录并授权站点文件
2. 选择站点和默认分支
3. 进入「文章管理」→ 添加，填好字段后保存
4. 约 30 秒后网站自动更新（或手动触发一次发布）

字段说明见站内文章《图文教程：用后台发布第一篇文章》。

如果托管平台不支持后台写入，也可以直接编辑 `content/*.json` 后重新发布，效果完全一样。

### 改站点名称、导航、页脚

后台「站点设置」里改，保存即生效。

> **在后台改了「站点名称」，还有 7 个文件需要同步手改。** 站名同时被写死在各个 HTML 的 `<title>` 里（以及 `index.html` 的 description），这是给「JavaScript 未加载」的兜底。只改后台不改这些文件，搜索引擎抓到的仍是旧名。需要同步的 7 个文件：`index.html`、`post.html`、`archive.html`、`tags.html`、`search.html`、`about.html`、`404.html`。

### 更换主题皮肤

站点内置 **6 套主题**，在后台「**站点设置 → 站点主题**」里用下拉框选择，保存后刷新页面即生效。

**拿不定主意？** 先打开主题预览页 `themes.html`。页面上点按钮就能当场切换对比（只影响当前页面、不会保存），下面是真实的文章列表和一段排版样例。这页标了 `noindex`、不在导航和站点地图里，纯粹是给你自己用的工具。

| 主题 | 定位 | 特点 |
| --- | --- | --- |
| **铅墨**（默认） | 中文长文阅读 | 暖白纸感、衬线标题、克制的轴线装饰 |
| **磐石** | 企业级 CMS / 官网 | 冷灰蓝、方正紧凑、无衬线、文章卡片双列网格 |
| **刊页** | 杂志 / 媒体 | 纯白、大标题、报头粗线、正文首字下沉、宽栏窄边距 |
| **白纸** | 极简个人博客 | 单栏窄版心、隐藏侧栏、去掉一切装饰、纯黑白 |
| **暖宣** | 纸感随笔 | 米黄底、大圆角、宽松留白、虚线分隔 |
| **终端** | 技术极客 | 等宽标题、直角、侧边竖线、深色模式下尤其出彩 |

每套主题都自带**明暗两套配色**，而且与右上角的明暗切换按钮**互相独立**：访客自己选深浅，站长决定整体风格，两者可任意组合。

**想换成自己的主色？** 后台「主题点缀色」填一个十六进制色值（例如 `#2E6E5E`）就会覆盖当前主题的主色；**留空则使用主题自带的配色**。

> 自己新增主题时，主题清单需要三处保持一致，缺一处就会出问题：`assets/css/style.css` 第 20 节的变量区块、`assets/js/app.js` 的 `SKINS` 数组、`.pages.yml` 里的下拉选项。

## 关于自定义域名（可选）

本站**默认不需要自定义域名**，用托管平台自带的地址即可。若以后要绑自己的域名，需要：一个域名 + 一个 DNS 解析与证书服务。逐步操作见《部署手册.md》。

若使用免费域名，请注意：它由志愿者团队运营，**没有可用性保障**，且**需要定期手动续期**，不建议用于生产级业务。
