## 零成本静态网站搭建（拾页 · 个人知识库）

**目标**：零成本网站，GitHub Pages 托管 + Pages CMS 后台 + DigitalPlat .US.KG 免费域名 + Cloudflare DNS/SSL。

**技术选型（用户确认）**
- 站点类型：个人博客 / 知识库
- 方案：**纯静态零构建**（不用 Astro/Hugo/Jekyll），Pages CMS 直接编辑 JSON 数据源
- 交付方式：用户选择「我全程代劳（需提供 GitHub Token）」，Token 待用户提供后执行推送

**架构决策**
- 内容统一存 JSON：`content/site.json`（站点设置）、`content/posts.json`（文章数组）、`content/about.json`
  - 选单文件 posts.json 而非 Markdown collection，因为无构建步骤时无法生成文章索引列表；排序改为浏览器端按 date 处理
- Pages CMS 用 `type: file` + `format: json` + `type: object` + `list: true`（含 collapsible/summary）实现文章增删改
- 日期字段用 `type: date` + `options.format: "yyyy-MM-dd"`，与数据格式一致
- marked.js 下载到 `assets/vendor/` 本地化，不依赖 CDN（考虑国内访问）
- 部署方式用 GitHub Pages「Deploy from a branch」（main / root），不用 Actions，规避构建故障
- 附 `.nojekyll` 防止 Jekyll 处理；`CNAME` 由部署脚本写入

**文件清单**（24 个文件，约 155KB）
- 页面：index / post / archive / tags / search / about / 404，全中文
- 样式：`assets/css/style.css`（明暗主题、响应式、打印样式）
- 脚本：`assets/js/app.js`（前端渲染、站内搜索、TOC、分页、主题切换）
- 工具：`tools/deploy.mjs`（一键建仓+推送+开启 Pages+绑定域名）、`tools/serve.mjs`（本地预览）
- 文档：`部署手册.md`（四段式图文教程）、`README.md`

**踩到的坑（已修复）**
- `postCardHtml` 最初把标签链接 `<a>` 嵌套在整卡链接 `<a>` 内部，属非法 HTML，浏览器会拆散卡片结构（jsdom 复现为卡片数翻倍）。改为「标题上的 `.post-link` 用 `::after` 覆盖整卡 + `.post-tags` 提 z-index」的标准写法。
- `deploy.mjs` 的 `--dry-run` 最初会真的改写 CNAME/sitemap/robots，已改为只检查不写入。

**验证方式**
- 用 jsdom（装在 `.workbuddy/binaries/node/workspace`）逐页加载真实 HTTP 渲染，13 个用例全通过：首页分页（4/2 篇）、文章正文与表格代码块、目录、上下篇、相关阅读、归档 6 篇、标签 12 个共 14 处引用、搜索命中 3 篇、404 与错误态
- 额外加入「页面内不得存在 a 嵌套 a」的不变量检查
- `.pages.yml` 用 yaml 库解析通过，且与三个 JSON 的字段声明**完全一一对应，无孤立字段**
